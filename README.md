# ARPG Mago v13

Versão estática para Netlify. O protótipo não usa localStorage/save.

Para máxima compatibilidade com Netlify, o navegador carrega `src/js/app.js` como script clássico.
Os arquivos modulares originais continuam presentes em `src/js/` para futura reorganização/build.

Controles: WASD, mouse, Espaço, 1/2 skills, 3 Aura, Shift Dash, P para árvore.
